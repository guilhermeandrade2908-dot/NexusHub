# 🇧🇷 Português

## 📝 Sobre

O **NexusHub** é uma aplicação web voltada para produtividade e organização pessoal. O projeto integra um front-end modular em **HTML, CSS e JavaScript** com uma **API REST em C# (.NET)** e **MySQL**, oferecendo uma arquitetura escalável para gerenciamento de estudos, projetos e metas.

---

## ✨ Funcionalidades

- 🏠 Dashboard de produtividade
- 📚 Gerenciamento de estudos
- 📁 Organização de projetos
- 🎯 Metas semanais (CRUD)
- 👤 Perfil personalizado
- 📈 Acompanhamento de progresso
- 🌙 Interface Dark Mode
- 🔄 Integração com API REST

---

## 🚀 Principais Implementações

### 📚 Estudos
- Organização de disciplinas e horas de estudo.
- Estrutura preparada para acompanhamento do progresso.

### 📁 Projetos
- Cadastro e gerenciamento de projetos.
- Persistência de dados.

### 🎯 Metas Semanais
- CRUD completo.
- Checkboxes.
- Atualização em tempo real.
- Modais de edição e exclusão.

### 👾 Lazer & Mídia
- CRUD completo.

### ⚙️ Backend

### 💻 Front-end

# 🇺🇸 English

## 📝 About

**NexusHub** is a web application focused on productivity and personal organization. It combines a modular **HTML, CSS and JavaScript** front-end with a **C# (.NET) REST API** and **MySQL**, providing a scalable architecture for managing studies, projects and weekly goals.

---

## ✨ Features

- 🏠 Productivity dashboard
- 📚 Study management
- 📁 Project management
- 🎯 Weekly goals (CRUD)
- 👤 User profile
- 📈 Progress tracking
- 🌙 Dark Mode
- 🔄 REST API integration
