# 🇧🇷 Português

## 📌 Sobre o Projeto

O **Nexus Hub 2.0** é a evolução do meu dashboard pessoal, reconstruído do zero para funcionar como um verdadeiro **Sistema Operacional para a Vida**. Seu objetivo é centralizar métricas diárias, horas de estudo, progresso de projetos, metas e momentos de lazer em uma única interface moderna, organizada e intuitiva.

Esta versão abandona completamente a arquitetura anterior e adota uma estrutura **modular**, baseada em **HTML5**, **CSS3**, **Vanilla JavaScript (ES Modules)** e **LocalStorage**, priorizando desempenho, organização e escalabilidade sem depender de frameworks.

---

## 🎨 Design & Filosofia

- 🌑 **Dark Cyber Aesthetic:** Interface escura (`#0d0d0d`) com detalhes em roxo.
- ⚡ **Produtividade em Primeiro Lugar:** Informações importantes disponíveis imediatamente.
- 🧩 **Arquitetura Modular:** Componentes reutilizáveis e organização por responsabilidades.
- 💾 **Persistência Local:** Dados armazenados diretamente no navegador através do LocalStorage.

# 🇺🇸 English

## 📌 About the Project

**Nexus Hub 2.0** is the evolution of my personal dashboard, completely rebuilt from scratch to work as a true **Life Operating System**. Its goal is to centralize daily metrics, study hours, project progress, goals, and leisure activities into a single modern, organized, and intuitive interface.

This new version replaces the previous architecture with a clean and modular structure powered by **HTML5**, **CSS3**, **Vanilla JavaScript (ES Modules)**, and **LocalStorage**, focusing on performance, maintainability, and scalability without relying on external frameworks.

---

## 🎨 Design & Philosophy

- 🌑 **Dark Cyber Aesthetic:** Deep dark interface (`#0d0d0d`) with purple accents.
- ⚡ **Productivity First:** Essential information is immediately available.
- 🧩 **Modular Architecture:** Reusable components and well-organized code.
- 💾 **Local Persistence:** Data is stored directly in the browser using LocalStorage.
